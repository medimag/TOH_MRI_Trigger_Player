# TOH MRI Trigger Music Player

This repository builds a Windows executable using GitHub Actions.

## How to build

1. Open the repository on GitHub.
2. Go to **Actions**.
3. Select **Build Windows EXE**.
4. Click **Run workflow**.
5. When finished, download the artifact named `TOH_MRI_Trigger_Music_Player_Windows_EXE`.
6. Unzip it to get `TOH_MRI_Trigger_Music_Player.exe`.

Default serial port is COM3.
